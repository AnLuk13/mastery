# Map Update Installation Guide

Reconfigure your navigation maps in 10 easy steps.

## Steps
1. **Download** the map package to your PC. You can re‑download it anytime from the *Purchases* section.
2. **Prepare USB**: Use an empty FAT‑32 USB stick (≥8 GB). Ensure it is formatted and empty.
3. **Extract** the ZIP contents to the root of the USB stick. Verify the root contains:
   - `nav/` directory
   - `KaliSWDL.log`
   - `swdl.iso` & `swdl.iso.md5`
   - `swdlInstall.iso` & `swdlInstall.iso.md5`
4. **Insert USB** into your vehicle; the installation will start automatically.
5. **Follow prompts** on the navigation screen as they appear.
6. **Confirm** the start of configuration by selecting **Yes**.
7. **Select region** (East or West) on the next screen.
8. **Choose countries** via *Select by country*. The screen shows memory usage and estimated upload time.
9. **Press Confirm** to begin the update (may take up to 90 minutes). Do not interrupt.
10. **Finish**: When prompted, remove the USB stick. Your navigation system is now updated.
